# Momento — Make Every Moment Special ✨

Premium balloon decoration at home across India for Birthdays, Anniversaries, Baby Showers, Kids Parties & Surprises.

## 🚀 Features & Architecture

- **Next.js 14 App Router & TypeScript**: Fast, server-optimized static and dynamic route generation.
- **Tailwind CSS**: Custom color themes, responsive layouts, and modern typography with Nunito & Plus Jakarta Sans.
- **Interactive Celebration Booking**:
  - 14-day Indian Standard Time (IST) date selector + custom calendar date picker.
  - 5 standard IST arrival windows + custom time selection.
  - Pin-code doorstep setup verification.
- **Celebration Cart & Add-ons**:
  - Interactive add-ons (*Customized 500g Cake, Foil Number Balloons, Party Poppers & Confetti, Warm Fairy Lights Curtain*) itemized directly in the cart drawer.
  - Dynamic subtotal, promo code engine (`MOMENTO200`), and direct WhatsApp booking payload integration.
- **Sticky PDP Gallery Experience**:
  - Two-column responsive layout where the product gallery stays sticky in viewport while the booking panel details scroll through completely.
- **HD Ultra Hero Banner**:
  - Razor-sharp 2x/3x super-sampled visuals with seamless background blending and GPU-accelerated scroll zoom.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build & Production Run
```bash
npm run build
npm start
```
